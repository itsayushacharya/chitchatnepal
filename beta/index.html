⚠️ Setup Required

Images and video calls need a few things configured in your Supabase project. Follow these steps once, then reload.

1. Add image_url column to messages

ALTER TABLE messages ADD COLUMN image_url TEXT;

2. Create a storage bucket named chat-images

In Supabase Dashboard → Storage → New bucket → name it chat-images → toggle Public bucket ON.

3. Add storage policies (SQL editor)

-- Allow anyone to read images
CREATE POLICY "Public read" ON storage.objects
  FOR SELECT USING (bucket_id = 'chat-images');

-- Allow authenticated users to upload
CREATE POLICY "Auth upload" ON storage.objects
  FOR INSERT WITH CHECK (bucket_id = 'chat-images' AND auth.role() = 'authenticated');

-- Allow users to update their own files
CREATE POLICY "Auth update" ON storage.objects
  FOR UPDATE USING (bucket_id = 'chat-images' AND auth.role() = 'authenticated');

4. Enable Realtime for video signaling

In Supabase Dashboard → Database → Replication → enable replication for a new table called call_signals:

CREATE TABLE call_signals (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  channel_id TEXT NOT NULL,
  sender_id UUID NOT NULL,
  signal_type TEXT NOT NULL,  -- 'offer' | 'answer' | 'ice' | 'hangup'
  payload JSONB,
  created_at TIMESTAMPTZ DEFAULT now()
);
ALTER TABLE call_signals ENABLE ROW LEVEL SECURITY;
CREATE POLICY "read all signals" ON call_signals FOR SELECT USING (true);
CREATE POLICY "insert own signals" ON call_signals FOR INSERT WITH CHECK (auth.uid() = sender_id);
-- Enable realtime on this table in Dashboard → Database → Replication

5. Enable video call signaling (optional but needed for real calls)

  • Camera/mic requires HTTPS (or localhost).
  • Both users must be in the same DM conversation.
