 Chitchat Nepal
A modern, real-time social chat application built for Nepal — connect, chat, and belong.

![Chitchat Nepal](https://raw.githubusercontent.com/itsayushacharya/chitchatnepal/refs/heads/main/images/icon.png)

## ✨ Features
- **💬 Public Lounges** — Join themed chat rooms like `#Chautari-Lounge`, `#Tech-Nepal`, and `#Gaff-Saff`
- **📩 Direct Messages** — Private 1-on-1 conversations with any online user
- **🟢 Live Presence** — See who's online in real time
- **🔔 Instant Notifications** — Sound alerts + clickable toast notifications that jump straight to the conversation
- **📱 Fully Responsive** — Optimized for mobile with slide-out drawers for lounges and users
- **🔐 Auth System** — Sign up with username/email, or jump in instantly as a guest
- **🎨 Modern UI** — Clean, social-media-style design with smooth animations
- **⚡ Real-time Everything** — Powered by Supabase Realtime (messages + presence)

## 🛠️ Tech Stack
| Layer | Technology |
|-------|-----------|
| Frontend | HTML5, Tailwind CSS (CDN) |
| Backend | Supabase (Auth, Postgres, Realtime) |
| Icons | Custom brand icon |
| Sound | Web Audio API (no audio files needed) |
